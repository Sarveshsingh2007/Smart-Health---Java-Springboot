# Smart Health Assistant — React Frontend

## Run
```bash
npm install
npm run dev
```

Set `VITE_API_URL` if backend is not at `http://localhost:8080/api`.

## Pages
- Minor Symptoms
- Appointment request
- Login/Register
- Patient dashboard
- Hospital dashboard + billing
- Admin dashboard

Role-based routes are protected on the UI and enforced again by Spring Security on the backend.
